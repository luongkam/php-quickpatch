Chuyển tuần tự, site đầu là canary; site kế tiếp chỉ mở khi site trước PASSED; mỗi lượt dry-run + xác nhận riêng (BR-ENV-003, BR-SCN-008). Lượt ROLLED_BACK/HC_FAILED_KEPT/ROLLBACK_FAILED → dừng các site còn lại, kế hoạch giữ in_progress (BR-UPG-003, T-PLN-08) tới khi người vận hành bấm "Xác nhận đã xử lý" (FR-UPG-ACK-001): trước xác nhận, ROLLBACK_FAILED → mọi lệnh chuyển trả ERR-UPG-423-01; ROLLED_BACK/HC_FAILED_KEPT → chuyển site kế tiếp trả ERR-UPG-409-03. Sau xác nhận: chuyển lại chính site đó bằng lượt mới hoặc chuyển site kế tiếp; mục P5 của site lỗi giữ FAILED tới khi chạy lại DONE hoặc WAIVED (BR-PLAN-007). Đổi canary: SCR-004 (BR-PLAN-004).
